# Extension Icons

This folder should contain the following icon files:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extensions page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Quick Setup

You can use any icon generator or create your own. Here's a simple approach:

### Option 1: Use the Icon Generator
Open `generate-icons.html` in a browser to generate placeholder icons.

### Option 2: Use an Online Tool
1. Go to https://favicon.io/ or https://www.canva.com/
2. Create a simple icon with:
   - Background: Blue gradient (#3b82f6 to #8b5cf6)
   - Text: "⚡" or "AF"
   - Style: Rounded corners
3. Download in sizes: 16x16, 48x48, 128x128

### Option 3: Use Default Chrome Extension Icons
The extension will work without custom icons, but will show a puzzle piece icon.

## Recommended Design
- Use a lightning bolt (⚡) on a blue/purple gradient background
- Keep it simple and recognizable at small sizes
- Consider the icon will appear on both light and dark toolbars
